# Plan: Update 7th Card Trump Handling

## Goal
Change the 7th card trump mechanic so that:
1. The 7th card is **removed** from the declarer's hand after the second deal (declarer plays with 7 cards)
2. The card sits face-down on the trump pile (only the declarer knows what it is)
3. When anyone reveals trump, the card flips face-up (shown to everyone), then **returns to the declarer's hand**
4. Trump suit activates at reveal time, game continues normally

## Files to Modify

### 1. `packages/games/twenty-nine/src/TwentyNineEngine.ts`

**In `proceedToSecondDeal` (~line 731-743):**
After determining the 7th card, **remove it from the declarer's hand** and store it in `state.trump.seventhCard`:
```ts
if (state.trump.type === 'seventh-card') {
  const declarer = state.players.find((p) => p.isDeclarer)!;
  const result = selectSeventhCardTrump(declarer.hand);
  state.trump.suit = result.suit;
  state.trump.seventhCard = result.seventhCard;

  // Remove the 7th card from declarer's hand (they play with 7 cards)
  const cardIndex = declarer.hand.findIndex(
    (c) => c.suit === result.seventhCard.suit && c.rank === result.seventhCard.rank
  );
  if (cardIndex !== -1) {
    declarer.hand.splice(cardIndex, 1);
  }

  // Tell the declarer the actual trump (private info)
  broadcasts.push({
    event: 'TRUMP_HIDDEN',
    payload: { suit: result.suit, seventhCard: result.seventhCard },
    targetPlayerIds: [declarer.id],
  });
}
```

**In `handleTrumpReveal` (~line 1042-1093):**
After marking trump as revealed, **return the 7th card to the declarer's hand** if it's seventh-card mode:
```ts
// For seventh-card trump, return the hidden card to the declarer's hand
if (state.trump.type === 'seventh-card' && state.trump.seventhCard) {
  const declarer = state.players.find((p) => p.isDeclarer)!;

}
```

Also broadcast the seventh card info to everyone so they can see it:
```ts
broadcasts.push({
  event: 'TRUMP_REVEALED',
  payload: {
    suit: state.trump.suit,
    playerId,
    seventhCard: state.trump.type === 'seventh-card' ? state.trump.seventhCard : undefined,
  },
});
```

**In `getVisibleState` (~line 224):**
The `handCount` already comes from `p.hand.length`, so it will automatically reflect 7 cards before reveal and 8 after. The `seventhCard` visibility logic stays the same (only declarer sees it before reveal). After reveal, everyone sees the suit via `isRevealed`.

No changes needed to `handlePlayCard` — the smaller hand naturally enforces the 7-card constraint.
