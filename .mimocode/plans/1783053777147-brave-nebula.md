# Restructure 29 Bidding System to Bangladeshi-style

## Current State

The bidding is **poker-style**: all 4 players bid in linear counter-clockwise order, each either raises or passes, and ends when 3 pass or all 4 pass. The `BidInfo` type tracks a simple highest-bid/lowest-pass model.

## Desired Behavior (Bangladeshi 29)

A **head-to-head duel** between the current bid holder and a challenger. Three actions exist: **Call** (match the bid, force opponent higher), **Raise** (go above current bid), **Pass** (eliminate yourself permanently). After each action, the turn flips to the other active party. When a player passes, the next counter-clockwise player who hasn't passed enters as the new challenger. The duel continues until only one active bidder remains.

## Worked Example

Dealer = P4. Bidding starts at P1. Seats are P1=0, P2=1, P3=2, P4=3.

1. P1 bids 16 (only valid opening action). Active duel: P1 vs P2.
2. P2 raises to 18. Duel flips: P2 vs P1.
3. P1 calls (matches 18). Duel flips: P1 vs P2. P2 must raise >18 or pass.
4. P2 passes. P2 eliminated. Next challenger = P3.
5. P3 passes. P3 eliminated. Next challenger = P4.
6. P4 passes. P4 eliminated. Only P1 remains -> P1 wins bid at 18.

If in step 3, P1 passes instead: P1 eliminated. Next challenger = P3. Duel becomes P2 vs P3.

## State Model Change

Replace the current `BidInfo` with a duel-oriented structure:

```typescript
interface BidInfo {
  currentBid: number | null;
  highestBidder: string | null;
  activeBidders: string[];          // player IDs still in contention
  currentChallenger: string | null; // whose turn it is to respond
  bids: { playerId: string; bid: number | null }[];
}
```

**Key state transitions:**
- `currentChallenger` is set after every action — it always flips to the OTHER party in the duel
- When `currentChallenger` passes, advance to the next counter-clockwise non-eliminated player
- When `currentChallenger` raises, they become `highestBidder`, and the old `highestBidder` becomes the new `currentChallenger`
- When `highestBidder` calls (matches), the old `currentChallenger` becomes the new `currentChallenger` (they must raise higher or pass)
- Bidding ends when `activeBidders.length === 1` (that player wins the bid)
- If all 4 players pass without anyone placing a bid, trigger a **redeal** (reshuffle, redeal, restart bidding)

**New action: `CALL_BID`** — available only to the `highestBidder` when it's their turn (after the challenger raised). Matches the current bid; forces the other party to raise higher or pass.
