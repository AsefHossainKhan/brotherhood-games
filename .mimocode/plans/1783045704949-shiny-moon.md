# Plan: Implement Seeded PRNG for Deterministic Card Dealing

## Context

The game "29" uses `crypto.getRandomValues()` in `shuffleDeck()` for all card shuffling, making it impossible to reproduce game states or create consistent test cases. We need a seeded PRNG so that:
- Same seed = same card dealing every time
- Tests can use fixed seeds for reproducibility
- Backward compatibility is maintained (no seed = current crypto behavior)

## Key Finding

**All gameplay randomness flows through a single function**: `shuffleDeck()` in `packages/games/twenty-nine/src/logic/deck.ts:22`. This is called from 4 locations in `TwentyNineEngine.ts` (lines 273, 323, 501, 1167). This makes the change surgically clean.

## Implementation

### Step 1: Create `packages/games/twenty-nine/src/logic/rng.ts`

New module with:
- `createSeededRng(seed)` — Mulberry32 PRNG returning `() => number` (float in [0,1))
- `splitmix32(x)` — Avalanche/mixing function for deriving uncorrelated seeds
- `createShuffleRng(baseSeed, index)` — Per-shuffle RNG derivation via `createSeededRng(splitmix32(baseSeed ^ index))`
- `generateRandomSeed()` — Web Crypto wrapper returning a single `number`

### Step 2: Add `seed?` to `RoomSettings`

**File**: `packages/shared/src/types/room.ts`

Add optional `seed?: number` field to the `RoomSettings` interface.

### Step 3: Extend `TwentyNineState`

**File**: `packages/games/twenty-nine/src/types.ts`

Add to the state interface:
- `randomSeed: number` — Match-level seed (from settings or crypto)
- `shuffleCount: number` — Tracks how many times deck has been re-shuffled

Add `seed?: number` to the `settings` sub-object.

### Step 4: Update `shuffleDeck` in `deck.ts`

**File**: `packages/games/twenty-nine/src/logic/deck.ts`

- Add optional `rng?: Rng` parameter
- When provided, use it instead of `cryptoRandomInt`
- Add a `cryptoRandomFloat()` fallback for the no-seed path
- Remove the old `cryptoRandomInt` (replaced by float-based approach)

### Step 5: Update `TwentyNineEngine.ts`

**File**: `packages/games/twenty-nine/src/TwentyNineEngine.ts`

- In `createInitialState()`: Initialize `randomSeed` from `settings.seed ?? generateRandomSeed()`, set `shuffleCount: 0`
- At all 4 shuffle call sites (lines 273, 323, 501, 1167): Increment `shuffleCount`, derive RNG via `createShuffleRng(state.randomSeed, state.shuffleCount)`, pass to `shuffleDeck()`

### Step 6: Add unit tests

**New file**: `packages/games/twenty-nine/src/logic/rng.test.ts`
- `createSeededRng`: values in [0,1), deterministic for same seed, differs for different seeds
- `splitmix32`: avalanches similar inputs, handles edge cases
- `createShuffleRng`: different indices produce different RNGs

**Update**: `packages/games/twenty-nine/src/logic/deck.test.ts`
- Add tests for seeded shuffle: same RNG produces same output, backward compatible without rng param

### Step 7: Add integration test

**Update**: `packages/games/twenty-nine/src/__tests__/TwentyNineEngine.test.ts`
- Test that two games with same seed produce identical initial deck state
