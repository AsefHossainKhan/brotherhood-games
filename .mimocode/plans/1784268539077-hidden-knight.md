# Plan: Add Marriage E2E Tests

## Context
Marriage feature is already implemented (engine, UI, unit tests). Now we need 2 Playwright E2E tests:
1. **Marriage broken** - K/Q of trump played before reveal → no marriage declared
2. **Marriage succeeds** - K+Q in hand at reveal → marriage declared, points change

## Test Design

### Test 1: Marriage Broken (seed: `40001`)
**Scenario:** Seventh-card trump mode. A player holds K+Q of the hidden trump suit but plays one or both cards before trump is revealed. After reveal, marriage should NOT be declared.

**Flow:**
1. `setupFullGame(players, { seed: '40001' })`
2. `doQuickBidding(players)` → P1 opens 16, others pass
3. `selectSeventhCardTrump(players)` → declarer picks 7th card mode
4. `skipDoublePhase(players)` → all pass
5. `waitForPlayingPhase(players)`
6. Play several tricks (3-4) → some players play cards, potentially including K/Q of hidden trump
7. When a player without the led suit gets turn → they click "Reveal Trump"
8. After reveal → marriage-panel should NOT appear (marriage broken)
9. Play remaining tricks until scoring
10. Verify scoring-panel does NOT show marriage info

**Key assertion:** `marriage-panel` testid should NOT be visible at any point.

### Test 2: Marriage Succeeds (seed: `40002`)
**Scenario:** Seventh-card trump mode. A player holds K+Q of the hidden trump suit and does NOT play them before reveal. After reveal, marriage IS declared.

**Flow:**
1. `setupFullGame(players, { seed: '40002' })`
2. `doQuickBidding(players)` → P1 opens 16, others pass
3. `selectSeventhCardTrump(players)` → declarer picks 7th card mode
4. `skipDoublePhase(players)` → all pass
5. `waitForPlayingPhase(players)`
6. Play tricks carefully → ensure marriage holder doesn't play K/Q of trump before reveal
7. When a player without the led suit gets turn → they click "Reveal Trump"
8. After reveal → `marriage-panel` testid SHOULD appear
9. Assert marriage panel content:
   - "Marriage Declared!" text
   - Suit name (e.g., "hearts (K + Q)")
   - Effective bid text
10. Play remaining tricks until scoring
11. Verify scoring-panel shows marriage info: "Marriage ({suit}) → Effective: {effectiveBid}"

**Key assertions:**
- `marriage-panel` visible after reveal
- Marriage panel contains correct suit and effective bid
- Scoring panel shows marriage adjustment

## New Helper: `revealTrump`
```typescript
export async function revealTrump(players: PlayerContext[]): Promise<PlayerContext> {
  // Find player with "Reveal Trump" button and click it
  for (const player of players) {
    const btn = player.page.getByRole('button', { name: 'Reveal Trump' });
    if (await btn.isVisible().catch(() => false)) {
      await btn.click();
      await player.page.waitForTimeout(500);
      return player;
    }
  }
  throw new Error('No player had "Reveal Trump" button visible');
}
```

## Seed Strategy
- Seeds are numeric strings passed to Mulberry32 PRNG
- Same seed = same card dealing order every time
- We need to find seeds where:
  - **Test 1 (broken):** A player has K+Q of trump suit in initial 8 cards, and plays them before reveal
  - **Test 2 (succeeds):** A player has K+Q of trump suit and keeps them until reveal
- Strategy: Use seeds `40001` and `40002`, run tests, observe card distribution, adjust if needed
